Tipos de documento del Sistema de Gestión Documental

Esta página explica cómo identificar si un documento corresponde a Manual (MN), Procedimiento (PR), Instructivo (IN), Formato (FR) o Protocolo (PT).

Manual (MN)

Describe cómo funciona un área. Incluye estructura, procesos principales y responsabilidades.

Procedimiento (PR)

Explica cómo se realiza un proceso de forma ordenada: quién lo hace, qué pasos seguir y qué resultados se esperan.

Instructivo (IN)

Guía más detallada que el procedimiento. Indica paso a paso cómo ejecutar tareas muy específicas.

Formato (FR)

Plantilla en blanco para registrar información de forma estandarizada. Al completarse se vuelve un registro o evidencia.

Protocolo (PT)

Reglas o acciones a seguir en situaciones concretas, sobre todo de seguridad, salud o emergencias.

Cómo elegir el tipo correcto

Si el documento describe cómo funciona un área, corresponde a Manual.

Si explica un proceso ordenado de inicio a fin, corresponde a Procedimiento.

Si detalla pasos muy específicos de ejecución, corresponde a Instructivo.

Si solo sirve para registrar datos, corresponde a Formato.

Si define reglas de actuación en situaciones concretas, corresponde a Protocolo.

Regla general

Cuando el tipo ya fue identificado, el contenido debe colocarse dentro de la plantilla corporativa correspondiente. Solo tendrá validez ese archivo.
