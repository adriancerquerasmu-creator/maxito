Plantillas corporativas del Sistema de Gestión Documental SMU Perú

El contenido redactado debe adecuarse a la plantilla corporativa antes del envío formal. Solo tendrá validez el archivo trabajado en la plantilla correspondiente.

Plantillas oficiales

Manual (MN)

Usa esta plantilla cuando el documento describa el funcionamiento general de un área, sistema o proceso.

https://bit.ly/PlantillaManualWord

Procedimiento (PR)

Usa esta plantilla cuando el documento formalice la secuencia ordenada de actividades de un proceso.

https://bit.ly/PlantillaProcedimientoWord

Instructivo (IN)

Usa esta plantilla cuando el documento explique cómo ejecutar una actividad concreta paso a paso.

https://bit.ly/PlantillaInstructivoWord

Formato (FR)

Usa esta plantilla cuando el documento tenga como finalidad principal registrar información o evidencia.

https://bit.ly/PlantillaFormatoExcel

Protocolo (PT)

Usa esta plantilla cuando el documento establezca reglas de actuación ante situaciones específicas.

https://bit.ly/PlantillaProtocoloWord

Reglas de uso de plantillas

  • Debes usar la plantilla corporativa correspondiente al tipo documental.
  • No corresponde alterar la estructura base corporativa.
  • El usuario debe trabajar sobre el cuerpo del documento y respetar la lógica de la plantilla.
  • No deben alterarse manualmente códigos, revisiones, encabezados ni bloques automatizados de control documental.
  • Debe usarse la versión vigente de la plantilla.

Preparación antes del envío

Antes de enviar el documento, debes tener como mínimo:

  • el contenido redactado;
  • el tipo documental correctamente definido;
  • la información organizada según la plantilla;
  • un archivo coherente y listo para pasar por validación documental.

Caso especial: Formato (FR)

En el caso de Formato (FR), la lógica esperada es usar la plantilla correspondiente para pegar allí los formatos o registros. No se plantea como un documento narrativo del mismo tipo que un Manual, Procedimiento, Instructivo o Protocolo.
