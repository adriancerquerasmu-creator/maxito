Plantillas corporativas del Sistema de Gestión Documental

Regla obligatoria: el contenido redactado debe copiarse y pegarse dentro de la plantilla corporativa correspondiente. Solo tendrá validez ese archivo.

Manual (MN)

Usa esta plantilla cuando el documento describa cómo funciona un área.

Enlace de plantilla: https://bit.ly/PlantillaManualWord

Procedimiento (PR)

Usa esta plantilla cuando el documento explique un proceso ordenado.

Enlace de plantilla: https://bit.ly/PlantillaProcedimientoWord

Instructivo (IN)

Usa esta plantilla cuando el documento detalle tareas muy específicas paso a paso.

Enlace de plantilla: https://bit.ly/PlantillaInstructivoWord

Formato (FR)

Usa esta plantilla cuando solo se requiera registrar información o evidencia.

Enlace de plantilla: https://bit.ly/PlantillaFormatoExcel

Protocolo (PT)

Usa esta plantilla cuando el documento establezca reglas o acciones para situaciones concretas.

Enlace de plantilla: https://bit.ly/PlantillaProtocoloWord

Importante

Si el tipo ya fue identificado, se debe volver a mostrar la plantilla correspondiente y recordar que solo tiene validez ese archivo.
